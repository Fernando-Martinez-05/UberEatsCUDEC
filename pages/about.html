description ¿Qué es DITS?

DITS es una aplicación web diseñada para facilitar la consulta de platillos, selección de alimentos y gestión de pedidos.

Los usuarios pueden consultar los platillos disponibles, seleccionar los productos que desean y registrar la información necesaria para realizar un pedido.

La aplicación está desarrollada como una Aplicación Web Progresiva (PWA) , por lo que puede utilizarse desde computadoras y dispositivos móviles.

lightbulb Propósito de DITS

El propósito de DITS es proporcionar una solución sencilla, moderna y accesible para la gestión de platillos y pedidos, integrando tecnologías web actuales como aplicaciones progresivas, geolocalización, mapas y almacenamiento de información.
