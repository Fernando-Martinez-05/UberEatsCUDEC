description Descripción de la aplicación

DITS es una aplicación web diseñada para facilitar la consulta y administración de platillos, así como la realización de pedidos.

La aplicación permite a los usuarios consultar los platillos disponibles, seleccionar sus alimentos y registrar la información necesaria para realizar un pedido.

DITS utiliza tecnologías web modernas y está diseñada como una PWA, permitiendo que pueda utilizarse desde dispositivos móviles y computadoras.

lightbulb Propósito de la aplicación

El propósito de DITS es ofrecer una solución sencilla para la gestión de platillos y pedidos, integrando herramientas como geolocalización, mapas y almacenamiento de información en la nube.
